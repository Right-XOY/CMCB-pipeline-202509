## 1. 赛题概况

碳化硅（SiC）是第三代半导体材料，外延层厚度是影响器件性能的关键参数。赛题采用 **红外干涉法**（无损伤测量）来确定外延层厚度：

- 外延层与衬底掺杂浓度不同 → 折射率不同
- 红外光入射后在 **外延层表面** 与 **衬底表面** 分别反射，两束反射光干涉形成干涉条纹
- 已知反射光谱（反射率 vs 波数）与入射角，反推外延层厚度

### 三个子问题

| 问题 | 内容 | 数据 |
|------|------|------|
| **Q1** | 仅考虑一次反射/透射（双光束干涉），建立确定外延层厚度的数学模型 | 无 |
| **Q2** | 基于 Q1 设计算法，计算 SiC 外延层厚度，并做结果可靠性分析 | 附件1（入射角 10°）、附件2（入射角 15°） |
| **Q3** | 推导**多光束干涉**的必要条件及其对厚度计算精度的影响；判断硅片测试结果是否出现多光束干涉，建立硅外延层厚度模型并计算；若 SiC 数据也存在多光束干涉，设法消除影响 | 附件3、附件4（硅晶圆片，10°/15°） |

### 关键难点

- 外延层折射率 **不是常数**，与掺杂载流子浓度、波长（波数）有关 → 模型是非线性的
- 波数（cm⁻¹）与波长（μm）的换算要统一
- 同一样品在不同入射角（10° / 15°）下结果应一致 → 可作为算法验证手段
- Q3 需先推导多光束干涉的 **必要条件（相位条件）**，再判断、再建模、再消除影响
- 可靠性 / 误差 / 敏感性分析是评阅重点，不能只给一个数字

## 2. 项目结构

```
CMCB-pipeline-202509/
├── background/          # 赛题原文、参考资料（B题.md / 参考论文.md）
├── config.yaml          # ★ 全局路径配置，代码统一从这里读路径
├── requirements.txt     # Python 依赖（随代码编写同步更新）
├── data/
│   └── raw/             # 附件1~4.xlsx（原始数据）
├── src/
│   ├── model/           # ★ 主代码：数据处理 + 模型求解（q1.py / q2.py ...）
│   └── visualize/       # ★ 生图代码：绘制论文所需图表
├── outputs/
│   ├── figures/         # ★ 输出图片（PDF/PNG，论文直接引用）
│   └── reports/         # q1.md / q2.md / q3.md：各题完整超详细过程与思路
└── result/              # ★ 数值结果（CSV 等，供论文表格引用）
```

**约定**

- 所有路径一律通过 `config.yaml` 读取，代码中不要硬编码路径
- 结果类数据（数值、表格）放 `result/`，配图放 `outputs/figures/`，过程报告放 `outputs/reports/`
- 原始数据（`data/raw/*.xlsx`）只读不改；清洗后的数据如需保存请放到 `data/` 下新建目录并加入 config
