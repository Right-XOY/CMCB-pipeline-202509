# 问题二 推导过程：双光束干涉模型的厚度反演算法

1. 先对问题二给定的 附件1 和 附件2 做数据预处理

- 先画x轴为波数，y轴为反射率的原始数据折线图，观察数据分布情况
- 发现数据在波数小于1000的时候有异常，需要进行裁剪（定性判断）
- 使用滑动窗口FFT确定裁剪的波数分界点（定量判断）
- 数据处理完以后，为保证FFT的有效性，要对裁剪后（留下波数大于分界点）的数据进行等间距重采样（线性插值法）
- 再画裁剪、重采样后的折线图，观察数据分布情况
- 先用Hampel滤波去异常值，再用基线校正（AsLS 非对称最小二乘去基线趋势），再用Savitzky‑Golay平滑降噪
- 最后绘制处理好的图

2. 然后我们的目标就是找到一组参数，包含厚度d以及Q1提出的两个模型的其他参数（两个模型各自的色散系数），使得理论计算出的反射率与实验数据的残差平方和最小（非线性最小二乘法优化问题）

3. 构建最小二乘目标函数。用两套入射角光谱同时参与拟合（附件1和附件2），厚度d、色散参数在两个附件之间共享：

- 模型一（Cauchy 色散）待优化物理参数：[厚度d、Cauchy 色散系数]
- 模型二（Sellmeier 色散）待优化物理参数：[厚度d、Sellmeier 色散系数]

4. 接下来，对预处理后的数据进行FFT变换，得到厚度d的初始参考值，再用差分进化算法找到色散系数的初始参考值。再规定厚度d和色散系数的约束范围

5. 采用L‑M算法寻找最优参数组合，最小化联合残差目标函数

6. 分别对模型一（Cauchy）、模型二（Sellmeier）各做一遍模型拟合

7. 开展拟合结果可靠性检验：

- 残差均值、标准差、均方根 RMSE，看模型拟合偏差大小
- 给光谱加入不同等级高斯噪声，观测参数漂移，测试抗噪声能力
- 用L-M的雅可比矩阵算参数协方差 → 给出 d 的 ±σ、95% 置信区间
- AIC/BIC模型对比：两模型参数数量不同，只看RMSE对 Sellmeier 不公平，用信息准则惩罚参数数，公平判定哪个模型更优

## 1. 数据预处理方案

### 1.1 原始数据观察（思路步骤 1）

对附件 1、附件 2 分别绘制反射率 $R$ 对波数 $\nu$ 的原始折线图，观察：

- 干涉条纹振荡是否清晰、包络是否平稳；
- 低波数区域是否存在异常（基线急剧抬升、噪声过大、条纹畸变）；
- 两角度数据是否呈现同一振荡周期（同一厚度 d 的体现）。

### 1.2 低波数异常裁剪（思路步骤 1）

**定性判断**：原始图中波数 $\nu < 1000\,\mathrm{cm^{-1}}$ 区域异常明显，先初步确认异常区间。

**定量判断——滑动窗口 FFT**：将 $R(\nu)$ 按窗口 $\nu \in [\nu_c - W/2,\ \nu_c + W/2]$ 做短时傅里叶变换（STFT），计算各窗口内的频谱能量/振荡强度。干涉条纹的有效成分在频域集中在光程频率 $f_0 = 2\bar n d\cos\bar\theta_1$ 处；当窗口落入异常区时，该主峰消失或频谱被噪声淹没。据此确定裁剪分界点 $\nu_{cut}$：

$$
\nu_{cut} = \min\Big\{\nu_c : E(f_0; \nu_c) \geq \eta\, E_{max}\Big\}
$$

其中 $E(f_0;\nu_c)$ 为窗口中心 $\nu_c$ 处的频带能量，$\eta$ 为阈值。裁剪后保留 $\nu \in [\nu_{cut},\ \nu_{max}]$。

### 1.3 等间距重采样（思路步骤 1）

FFT 要求输入为**均匀采样**序列，而原始波数点未必等距，故在裁剪区间内按固定步长 $\Delta\nu$ 线性插值重采样：

$$
R^{res}(m\Delta\nu) = R(\nu_k) + \frac{R(\nu_{k+1}) - R(\nu_k)}{\nu_{k+1}-\nu_k}\,(m\Delta\nu - \nu_k)
$$

采样点数 $N = \lfloor(\nu_{max}-\nu_{cut})/\Delta\nu\rfloor + 1$。重采样后再次绘图检查。

### 1.4 基线校正与降噪（思路步骤 1）

处理顺序：**Hampel 滤波 → AsLS 基线校正 → Savitzky–Golay 平滑**。

1. **Hampel 滤波**：滑动窗口中位数滤波变体，剔除孤立异常值。对窗内点 $x_i$，若 $|x_i - \mathrm{med}| > t\,\sigma_{MAD}$ 则以中位数替换（$t$ 为阈值，$\sigma_{MAD}$ 为绝对中位差），去除尖峰异常。
2. **AsLS 非对称最小二乘基线校正**：最小化

$$
\min_{\mathbf{z}}\ \sum_i w_i\,(R_i - z_i)^2 + \lambda\sum_i (\Delta^2 z)_i^2
$$

   其中权重 $w_i = p$（当 $R_i > z_i$）或 $1-p$（当 $R_i \leq z_i$），$p\ll1$ 使拟合基线 $z_i$ 贴附谱线下包络。校正后 $R^{corr} = R^{res} - z$，去除慢变背景趋势。
3. **Savitzky–Golay 平滑**：在滑动窗内做多项式最小二乘拟合求平滑值，保留峰形与振荡细节，降低随机噪声。

> **要点**：Hampel 去孤立点在前，AsLS 去慢变基线居中，SG 平滑最后收尾；三者顺序不宜颠倒。

## 2. 反演问题形式化：联合非线性最小二乘（思路步骤 2、3）

### 2.1 决策变量与模型

由 Q1 推导，理论反射率为：

$$
R(\nu;\ \theta_0, d, \boldsymbol{\beta})
= r_{01}^2 + (1-r_{01}^2)^2 r_{12}^2
  + 2\,r_{01}r_{12}(1-r_{01}^2)\cos\big(4\pi\, n_1(\nu;\boldsymbol{\beta})\, d\cos\theta_1\,\nu\big)
$$

其中 $r_{01}, r_{12}$ 由菲涅尔公式给出（含入射角 $\theta_0$），色散折射率：

- **模型一（Cauchy）**：$n_1(\nu;\boldsymbol{\beta}) = A + B\nu^2 + C\nu^4$，待优化参数 $\boldsymbol{\theta} = (d, A, B, C)$；
- **模型二（Sellmeier）**：$n_1^2(\lambda;\boldsymbol{\beta}) = 1 + \frac{B_1\lambda^2}{\lambda^2 - C_1} + \frac{B_2\lambda^2}{\lambda^2 - C_2}$，待优化参数 $\boldsymbol{\theta} = (d, B_1, C_1, B_2, C_2)$。

### 2.2 联合目标函数（双角度共享 d）

同一晶圆片在两个入射角（附件 1：$\theta_0^{(1)}=10°$，附件 2：$\theta_0^{(2)}=15°$）下测量，**厚度 d 与色散参数一致**，仅 $\theta_0$ 不同。构造联合残差平方和：

$$
\min_{\boldsymbol{\theta}}\ S(\boldsymbol{\theta}) =
\sum_{i=1}^{2}\ \sum_{k=1}^{N_i}
\Big[ R^{mod}\big(\nu_{i,k};\ \theta_0^{(i)}, \boldsymbol{\theta}\big) - R^{obs}_{i}(\nu_{i,k}) \Big]^2
$$

- 输入：附件 1、附件 2 预处理后的 $( \nu_{i,k},\ R^{obs}_{i,k})$；
- 输出：最优参数 $\hat{\boldsymbol{\theta}}$，其中厚度 $\hat d$ 为核心结果；
- 特点：两角度数据联立，参数自由度不增加而数据量翻倍，**提高参数可辨识性**，是可靠性分析的重要依据。

## 3. 参数初值估计（思路步骤 4）

非线性最小二乘对初值敏感，先用全局手段获得可靠初值。

### 3.1 FFT 求厚度 d 初值

反射谱可写为（忽略色散的缓变影响）：

$$
R(\nu) = DC + AC\cos(2\pi\, f_0\,\nu), \qquad f_0 = 2\,\bar n\, d\cos\bar\theta_1
$$

对 $R(\nu)$ 做 FFT，频谱幅值在光程频率 $f_0$ 处出现主峰。由峰值位置反推厚度初值：

$$
d_0 = \frac{f_0}{2\,\bar n\cos\bar\theta_1}
$$

其中 $\bar n$ 为观测波数区间的平均折射率，$\bar\theta_1$ 由 Snell 定律按 $\bar n$ 计算。**精度注意**：

- 频率分辨率 $\Delta f = 1/(\nu_{max}-\nu_{cut})$，可用零填充提高峰值定位精度；
- 色散使 $n_1(\nu)$ 随 $\nu$ 变化，$f_0$ 峰被展宽（chirp 效应），故 $d_0$ 仅为参考值，作优化初值足够。

### 3.2 差分进化（DE）求色散系数初值

在约束范围内用差分进化做全局搜索：

1. 种群个体 = 色散系数向量 $\boldsymbol{\beta}$（d 固定为 $d_0$）；
2. 变异、交叉、选择迭代，最小化目标 $S(d_0, \boldsymbol{\beta})$；
3. 收敛后取最优 $\boldsymbol{\beta}_0$ 作为色散系数初值。

DE 不依赖梯度，能跳出局部最优，为 L-M 提供好的出发点。

### 3.3 参数约束范围（物理约束）

| 参数 | 约束 | 依据 |
|---|---|---|
| 厚度 $d$ | $d \in [0.1, 200]\,\mathrm{\mu m}$ | 外延层典型厚度量级 |
| Cauchy $A, B, C$ | $A>0,\ B,C$ 可取负（依材料） | 折射率恒正、量级合理 |
| Sellmeier $B_1, B_2 > 0$，$C_1, C_2$ | 振子强度正、谐振波数在测量区间外 | 物理意义要求 |
| 折射率 | $1.5 < n_1 < 4$ | SiC 红外折射率范围 |

## 4. 精细优化：L-M 算法（思路步骤 5）

L-M（Levenberg–Marquardt）是高斯–牛顿法与梯度下降的混合，适合非线性最小二乘。迭代格式：

$$
\big(\mathbf{J}^T\mathbf{J} + \lambda\,\mathrm{diag}(\mathbf{J}^T\mathbf{J})\big)\,\Delta\boldsymbol{\theta}
= -\mathbf{J}^T\mathbf{r}
$$

$$
\boldsymbol{\theta}^{(k+1)} = \boldsymbol{\theta}^{(k)} + \Delta\boldsymbol{\theta}
$$

其中 $\mathbf{r}$ 为残差向量（含双角度全部数据点），$\mathbf{J} = \partial \mathbf{r}/\partial\boldsymbol{\theta}$ 为雅可比矩阵（数值差分或解析求导），$\lambda$ 自适应调节：

- 迭代使 $S$ 下降 → 减小 $\lambda$（向高斯–牛顿靠拢，快速收敛）；
- 迭代使 $S$ 上升 → 增大 $\lambda$（向梯度下降靠拢，保证稳定下降）。

**收敛判定**：$\|\Delta\boldsymbol{\theta}\|$ 或 $|S^{(k+1)}-S^{(k)}|$ 小于容差，或梯度范数足够小。

> 实现：scipy.optimize.least_squares 以初值 $(d_0, \boldsymbol{\beta}_0)$ 启动，边界约束 + 双角度联合残差，即可完成 L-M 求解。

## 5. 两模型求解流程（思路步骤 6）

```
            ┌──────────────────────────────┐
            │  附件1 + 附件2 预处理数据       │
            └──────────────┬───────────────┘
                           ▼
            ┌──────────────────────────────┐
            │  FFT → d 初值 d0               │
            │  DE → 色散系数初值 β0          │
            └──────────────┬───────────────┘
                           ▼
        ┌──────────────────┴──────────────────┐
        ▼                                     ▼
┌───────────────┐                    ┌───────────────┐
│ 模型一 Cauchy  │                    │ 模型二 Sellmeier│
│ L-M 联合拟合   │                    │ L-M 联合拟合    │
│ → d1, A,B,C   │                    │ → d2, B1C1B2C2  │
└───────┬───────┘                    └───────┬───────┘
        └────────────────┬──────────────────┘
                         ▼
            ┌──────────────────────────────┐
            │ 可靠性检验 + 两模型对比择优     │
            └──────────────────────────────┘
```

**注意**：两模型各自独立执行"初值估计 → L-M 拟合"全流程，参数不共享（除 d 在两角度间共享），最后对比选择更优模型。

## 6. 可靠性检验方案（思路步骤 7）

### 6.1 拟合优度

- 残差均值 $\bar r$、标准差 $\sigma_r$、均方根误差 $RMSE = \sqrt{S/N}$；
- 决定系数 $R^2 = 1 - S/\sum(R^{obs}-\overline{R^{obs}})^2$；
- **AIC/BIC 模型对比**（模型参数数不同，必须惩罚复杂度）：

$$
AIC = N\ln(S/N) + 2p, \qquad BIC = N\ln(S/N) + p\ln N
$$

其中 $p$ 为参数个数（Cauchy：4；Sellmeier：6）。AIC/BIC 更小者更优，避免"参数多=拟合好"的假象。

### 6.2 参数不确定性（L-M 雅可比 → 置信区间）

最优解 $\hat{\boldsymbol{\theta}}$ 处残差方差估计：

$$
\hat\sigma^2 = \frac{S(\hat{\boldsymbol{\theta}})}{N - p}
$$

参数协方差矩阵：

$$
\Sigma_{\boldsymbol\theta} = \hat\sigma^2\,(\mathbf{J}^T\mathbf{J})^{-1}
$$

厚度 $d$ 的 95% 置信区间：

$$
\hat d \pm t_{0.975,\,N-p}\,\sigma_{\hat d}
$$

$t$ 为 Student 分布分位数。置信区间越窄，厚度结果越可靠。

### 6.3 抗噪声能力测试

对预处理后的 $R^{obs}$ 加入不同等级高斯噪声，观测参数漂移：

$$
R^{noisy} = R^{obs} + \varepsilon,\qquad \varepsilon \sim \mathcal{N}(0, \sigma_n^2),\quad \sigma_n = \eta\cdot \mathrm{std}(R^{obs})
$$

$\eta$ 取 1%、2%、5%、10% 多档；每档重复 M 次（如 50 次）重新拟合，统计 $\hat d$ 的均值与标准差。**判定标准**：噪声等级升高时 $\hat d$ 漂移小且仍在 6.2 置信区间内，说明算法抗噪稳健。

### 6.4 双角度一致性交叉验证

将附件 1、附件 2 **分别独立**拟合得到 $\hat d^{(1)}$、$\hat d^{(2)}$，与联合拟合 $\hat d$ 对比：

$$
\Delta^{(i)} = \left|\hat d^{(i)} - \hat d\right|
$$

三者偏差小于阈值（如 1%）→ 支持"同一厚度"物理事实，模型可信度高。

### 6.5 残差结构分析

- 残差对波数作图，检查是否围绕 0 随机分布；
- **若残差出现周期性振荡** → 说明双光束模型遗漏了多次反射成分（多光束干涉），为 Q3 的判定与建模留伏笔；
- 残差自相关检验（如 Ljung–Box），判断是否为白噪声。
